# Criterios de Revisao Cientifica

1. Toda afirmacao clinica relevante tem fonte?
2. Existe contradicao entre diretrizes citadas?
3. Existem dados potencialmente desatualizados?
4. O texto esta objetivo para formato de aula/slide?
5. Existem trechos genericos sem ganho pratico?
6. Os pontos de decisao medica estao explicitos?
7. A narrativa esta coerente com o briefing da aula?
